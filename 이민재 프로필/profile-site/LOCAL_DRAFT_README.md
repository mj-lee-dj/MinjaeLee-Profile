# Editorial Noir V13 초안

## 시작 파일

- 사이트: `draft-v2.html`
- 통합 관리자: `admin-profile-final.html`
- 디자인 계약: `DESIGN.md`

로컬 파일로 열면 모든 항목 편집과 미리보기는 브라우저 localStorage에만 남는다. 상단 운영 저장 버튼도 API를 호출하지 않고 배포된 관리자 주소를 안내한다.

## 편집과 이미지

- 프로필, PROOF, 저서, 온라인 연수, Watch, 강의, 수상, 활동, 보도자료를 추가·수정·정렬·공개·삭제할 수 있다.
- 온라인 연수·Watch·강의 썸네일은 경로 입력, `Ctrl+V`, 파일 선택을 지원한다.
- 필수·선택 정보는 라벨에 표시되며 온라인 연수 소개와 강의 설명은 받지 않는다.
- 붙여넣은 이미지는 최대 1600px·900KB WebP로 줄이고 강의는 최대 3장을 받는다.

## 운영 저장 경계

- 배포된 HTTPS 관리자에서 상단 `운영 사이트 저장 및 배포`를 누르면 로그인을 거쳐 전체 초안을 검증한다.
- 붙여넣은 이미지를 먼저 업로드하고 데이터와 이미지 blob을 한 Git 커밋으로 저장한다.
- 다른 기기 변경·삭제를 감지하면 저장 전에 중단하고 새로고침을 안내한다.
- 운영 `data_v3.json`이 새 내용과 일치할 때만 완료로 표시한다.
- 실제 운영 검증 전까지 관리자 페이지는 HOLD 상태다.

## 검증 기록

- 브라우저 붙여넣기·WebP 변환·공개 미리보기 통과
- 로컬 API 호출 0회, 호스팅 모의 업로드→저장→운영 확인 통과
- 375·768·1280px 가로 넘침 0, 모바일 dialog 행동 영역·키보드 포커스 통과
- 증거: `../.omo/evidence/profile-v13/`

## 배포 금지

사용자 승인 전 commit·push·Vercel 배포를 하지 않는다. 승인 후 운영 진입 파일 통합과 실제 도메인 E2E를 별도 수행한다.
